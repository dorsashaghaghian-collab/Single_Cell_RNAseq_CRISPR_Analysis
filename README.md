# Single-cell RNA-seq CRISPR Screen Analysis

## Project Overview

This project presents an end-to-end bioinformatics workflow for processing and analyzing single-cell CRISPR screening RNA-seq datasets.

The workflow includes:

- Raw sequencing data acquisition
- FASTQ quality assessment
- Read preprocessing
- Genome alignment
- Gene expression quantification
- Transcriptomic analysis
- Biological interpretation
