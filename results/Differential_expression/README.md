# Differential Expression Analysis

Differential expression analysis was performed using pseudobulk aggregation followed by DESeq2.

Cells were aggregated according to CRISPR perturbation identity.

Comparisons:

- sgAxl vs control
- sgPrmt1 vs control
- sgRipk1 vs control


## Main findings

### Axl perturbation

Axl knockout showed significant transcriptional changes including:

- Reduced Axl expression
- Activation of MYC-associated transcriptional programs


### Prmt1 perturbation

Prmt1 knockout produced broad transcriptional remodeling.

Major altered genes included:

- Nqo1
- Prmt1
- Col3a1
- Ccl7


### Ripk1 perturbation

No individual genes passed multiple testing correction thresholds.

However, pathway-level analysis revealed strong biological effects.
