# Analysis Pipeline


## Raw sequencing processing

FASTQ files were processed from SRA-derived sequencing data.


## Alignment

STARsolo was used for alignment and generation of gene-barcode matrices.


## Single-cell analysis

Seurat was used for:

- Quality control
- Normalization
- Dimensionality reduction
- Clustering
- Marker identification


## Biological interpretation

Future analysis includes:

- gRNA assignment
- Perturbation grouping
- Differential expression
- Pathway analysis
